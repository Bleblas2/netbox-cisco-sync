# README Images

This directory contains the original UI screenshots and the animated overview
used by the project README:

- `netbox-cisco-sync-demo.gif` — animation embedded at the top of `README.md`;
- `settings.jpg`, `devices_sync.jpg`, `device_edit.jpg`,
  `devices_sync_preview.jpg`, `sync_runs.jpg`, `sync_runs_detail.jpg`,
  `dcim_devices.jpg`, and `dcim_sites.jpg` — source screenshots retained for
  detailed inspection and future animation updates.

Keep screenshots cropped to the relevant NetBox view. Never include production
hostnames, credentials, API tokens, public addresses, or customer information.
Before publishing the repository, review every frame of the GIF as well as each
source image because an animation can retain data from all input screenshots.
